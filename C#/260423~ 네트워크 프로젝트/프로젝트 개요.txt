	## **프로젝트명 미정**

### 기간 : 2026.04.23 ~ 2026.05.19 (약 3주)

**장르:** 멀티플레이 숨바꼭질 + 슈팅

**최대 인원:** 8명

**팀 구성:** 5인

- 조진행 — UI/UX
- 안정연 — 네트워크
- 나현수 — AI
- 이승열 — 3인칭 플레이어
- 김동현 — 게임 시스템

### **핵심 메커니즘**

#### **1페이즈 (숨바꼭질)**

- 3인칭 시점
- AI NPC들 사이에 플레이어들이 섞여 숨어있음
- 서로를 찾아서 조준
- 일정 시간 후 탑뷰로 전환 + AI NPC 사라짐
- 플레이어들은 조준한 대로 발사
- 한 명만 남을 때까지 반복

### **레퍼런스**

- 후즈후 (AI 사이 숨바꼭질)
- 로블록스 블라인드 건 (조준 + 총격전)

### 후순위
- 볼륨
- 폴리싱

### 미정된 추가 사항
- 사망자 채팅 기능
- Tap 등을 누르면 접속자 리스트 표시(사망자 생존자 표시 기능 있을 수도 있음)
- 꾸밈 요소 추가 > 해당 꾸밈 요소들을 AI에게 랜덤 적용
- 두 명만 남으면 페이즈 2 돌입할 수도 있음

### UI 영역

- 타이틀 화면
- 멀티 플레이 로비

**게임 시스템 → UI 이벤트**

- 타이머 업데이트 → 남은 시간 표시
- 플레이어 사망 → 남은 플레이어 수 업데이트
- 페이즈 전환 → 탑뷰 전환 연출
- 플레이어 사망 → 사망 화면
- 게임 종료 → 결과 화면

**플레이어 → UI 이벤트**

- 조준 중 → 크로스헤어 표시
- 조준 해제 → 크로스헤어 숨김
